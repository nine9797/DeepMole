DeepMole снимает главную боль zapret: больше не нужно вручную перебирать `general.bat`, `ALT`, `FAKE TLS` и проверять глазами, что заработало. Программа разбирает стратегии на блоки (YouTube, Discord, общий список), проверяет каждый блок реальными загрузками и собирает конфигурацию из тех вариантов, которые прошли проверку.

## Возможности

- Подбор стратегии за 10–40 секунд на новой сети, мгновенный старт на известной стратегии.
- 28 стартовых пресетов из сборки Flowseal и собственный генератор на параметрах zapret: методы desync, fooling, split-pos, паттерны seqovl, fake-TLS с модификаторами, repeats, TTL и autottl, wssize. Вместе это больше двухсот тысяч уникальных рецептов, которые перебираются по одному параметру от лучшего частично рабочего варианта.
- Независимый подбор для YouTube, Discord и Telegram: если для одного сервиса подошёл один метод, а для другого другой, они объединяются в один запуск winws.
- Защита от подмены DNS: если DNS провайдера не отдаёт адрес сайта, пробы идут через DoH или публичный DNS, а программа сама переключает Windows на тот резолвер, который отвечает в этой сети (Google, Cloudflare, Quad9 или AdGuard, по возможности с шифрованием). При выходе прежние настройки DNS возвращаются.
- Память по сети: отпечаток считается по шлюзу, его MAC и SSID, стратегия сохраняется и поднимается сразу при следующем запуске.
- Сторож: раз в минуту проверяет ключевые сайты и переподбирает стратегию, если она сломалась или сменилась сеть.
- Окно статуса с журналом подбора, трей, кнопки «Переподобрать», «Выключить», «Автозапуск».
- При выходе и даже при аварийном завершении winws гарантированно останавливается, а драйвер WinDivert выгружается из системы.

## Установка

Скачайте `DeepMole-<версия>-setup.exe` со [страницы релизов](../../releases/latest) и запустите. Установщик ставит DeepMole вместе с winws, WinDivert и списками, добавляет ярлык в меню «Пуск», по галочке включает запуск при входе в Windows и сразу запускает программу. Никаких ручных шагов не нужно.

При удалении через «Приложения и возможности» обход останавливается, задача автозапуска и драйвер WinDivert удаляются.

Портативные варианты лежат там же:

- `DeepMole-<версия>-full-windows-x64.zip` — вместе с winws, WinDivert и списками, распакуйте и запустите `deepmole.exe`;
- `DeepMole-<версия>-windows-x64.zip` — только DeepMole, если zapret у вас уже есть.

Программа при старте запрашивает права администратора: они нужны драйверу WinDivert. Если взяли архив без zapret, положите папки `bin` и `lists` из [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle) или сборки [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) в папку `zapret` рядом с `deepmole.exe` или укажите путь в `deepmole.json`:

```json
{
  "zapret_dir": "C:/zapret",
  "game_filter": "off",
  "probe_timeout_ms": 3000,
  "watchdog_interval_s": 60,
  "max_candidates": 30,
  "secure_dns": "auto",
  "auto_update": "ask",
  "telegram": "on",
  "language": ""
}
```

`game_filter` принимает `off`, `tcp`, `udp`, `all` и включает обход для портов 1024–65535, как Game Filter в сборке Flowseal. `max_candidates` ограничивает число вариаций после пресетов: все 28 пресетов проверяются всегда, а дальше перебирается не больше указанного числа соседних рецептов. `secure_dns` принимает `auto` и `off`; тот же переключатель есть в окне и в меню трея, и выбор из окна запоминается. `auto_update` принимает `ask` (спросить при появлении новой версии), `auto` (поставить сразу) и `off` (только вручную из меню трея). `telegram` принимает `on` и `off` и включает третий блок подбора, см. ниже. `language` принимает `ru` или `en`, при пустом значении берётся язык интерфейса Windows.

Перед запуском остановите другие экземпляры zapret, GoodbyeDPI и подобных программ, иначе проверки будут давать неверный результат.

## Как это работает

1. При запуске определяется отпечаток сети.
2. Если для этой сети уже есть сохранённая стратегия, она поднимается сразу и проверяется в фоне.
3. Если сохранённой нет или она перестала работать, запускается поиск: сначала проверенные пресеты, затем вариации лучшего из них по одному параметру (TTL и autottl, fooling, fake-TLS, split-pos, метод desync, repeats, паттерн, wssize). Поиск останавливается на первом варианте, прошедшем все пробы блока.
4. Блоки YouTube и Discord подбираются независимо и объединяются в одну командную строку winws.
5. Каждый кандидат проверяется загрузкой реальных страниц и картинок, а не одним HEAD-запросом, чтобы ловить обрыв соединения после первых килобайт. Контрольные незаблокированные сайты отличают «упал интернет» от «сломалась стратегия».
6. Если системный DNS не отдаёт адрес проверяемого сайта, проба резолвит его сама: сначала через DoH (Google, Cloudflare, AdGuard), затем через обычный DNS к публичным серверам. Так подбор оценивает только обход DPI, а не ошибки DNS. При первой такой подмене программа переключает активные сетевые адаптеры на ответивший резолвер и включает DoH в Windows, если он доступен в этой сети; при выходе, выключении обхода или снятии переключателя настройки возвращаются.

## Telegram

Экспериментально, вживую не проверялось. Telegram не ходит по TLS с именем сайта: клиенты общаются по MTProto с IP дата-центров, поэтому обычные стратегии по hostlist к нему не применимы. DeepMole делает отдельный блок подбора:

- проба: настоящий MTProto-запрос `req_pq_multi` к двум дата-центрам Telegram по TCP 443, блок считается рабочим, когда оба отвечают;
- стратегии: набор пресетов с `--dpi-desync-any-protocol=1` (fake с badseq, ts и md5sig, multisplit, multidisorder, fakedsplit, syndata) и те же вариации по одному параметру, что и для других блоков;
- фильтр: `--ipset` с официальными диапазонами Telegram на TCP 80, 443 и 5222, файл `lists/ipset-telegram.txt` создаётся автоматически;
- веб-домены (`web.telegram.org`, `telegram.org`, `t.me` и другие) добавляются в общий блок через `lists/list-telegram.txt`;
- звонки: fake-пакеты на UDP 590–1400 и 3478 к диапазонам Telegram.

Что это не решает: замедление медиа после первых сотен килобайт и шейпинг аплоада, которые ТСПУ делает уже внутри установленного MTProto-соединения; против них нужен прокси вроде tg-ws-proxy. Отключить блок можно ключом `telegram: "off"`.

## Окно и трей

При запуске открывается окно статуса: состояние обхода, текущая сеть, стратегии для YouTube и Discord, строка DNS (системный, защищённый или подменяется провайдером) и журнал подбора, где по каждому кандидату видно, сколько проверок он прошёл. Закрытие окна сворачивает программу в трей, клик по иконке открывает его снова.

- **Переподобрать**: заново запустить поиск для текущей сети.
- **Выключить / Включить**: остановить или поднять обход, не закрывая программу.
- **Защищённый DNS**: разрешить программе переключать DNS Windows при подмене со стороны провайдера. Снятие переключателя сразу возвращает прежние настройки.
- **Автозапуск**: задача планировщика с запуском от администратора при входе.
- **Лог**: `deepmole.log` рядом с программой, там видны все пробы и кандидаты.
- **Выход** в меню трея останавливает winws и закрывает программу.

Сохранённые стратегии и выбор переключателя DNS лежат в `deepmole-state.json`, резервная копия настроек DNS на время работы — в `deepmole-dns.json`. Если программу убили без восстановления, при следующем запуске она вернёт настройки сама.

## Обновления

При запуске и раз в сутки программа запрашивает последний релиз на GitHub и сравнивает его с текущей версией. Если вышла новая, в окне появляется кнопка «Обновить до …», а в меню трея такой же пункт; в режиме `ask` дополнительно задаётся вопрос, в режиме `auto` обновление ставится сразу. Установщик или lite-архив скачиваются только с github.com/nine9797/DeepMole и проверяются по SHA256 из файла `SHA256SUMS` в релизе. Установленная версия обновляется тихой установкой с перезапуском программы, портативная подменяет `deepmole.exe` и `deepmole-cli.exe` после выхода. Пункт «Проверить обновления» в трее работает и при `auto_update: "off"`.

## Сборка из исходников

Нужен Go 1.22+.

```powershell
.\build.ps1 -Version 1.0.3
```

Скрипт генерирует иконку, ресурсы exe (иконка и манифест с запросом прав администратора) и собирает `dist/deepmole.exe` (без консоли) и `dist/deepmole-cli.exe` (с выводом в консоль). `release.ps1` упаковывает zip-архивы, а с параметром `-ZapretDir` ещё полный пакет и установщик (нужен Inno Setup 6). Релизы на GitHub собираются автоматически по тегу `v*`.

Ключи командной строки:

```
deepmole-cli.exe -cli            запуск в консоли с логом
deepmole-cli.exe -dry            показать аргументы winws и прогнать пробы без запуска обхода
deepmole-cli.exe -ui             показать окно с примером данных, без запуска обхода
deepmole-cli.exe -zapret <dir>   путь к папке с bin и lists
deepmole-cli.exe -game all       включить Game Filter
```

Тесты:

```powershell
go test ./...
```

## Антивирусы

WinDivert может определяться антивирусом как потенциально нежелательная программа. Это драйвер перехвата трафика, без него обход не работает. Добавьте папку в исключения.
